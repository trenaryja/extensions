### Live, and in place

Marksmith is the default editor for `.md` files — open any markdown file and you're already in it.

- **What you see _is_ the markdown.** No split preview; formatting reveals as your cursor lands on it.
- **Toggle raw text** anytime with `⌘⇧M` (`Ctrl+Shift+M`).
- **Your formatter is respected** — edited tables come out exactly as Prettier would write them, so save-on-format never fights you.
