# Changelog

All notable changes to this project will be documented in this file.

## [0.0.2] - 2026-08-06

Initial public release.

### Added

- Live in-place markdown preview — headings, emphasis, lists, task lists, blockquotes, links, and images render as you type, while the file stays plain markdown on disk
- The active line reveals its raw markdown for precise edits, then re-renders once you leave it
- Find and replace with `Cmd+F` / `Cmd+Alt+F`, with match count and case/word/regex toggles
- Spreadsheet-style editing for GFM tables — range selection, markdown-aware copy/paste, drag to reorder rows and columns, and optional source auto-formatting
- Obsidian's full callout taxonomy, including folds, nesting, custom titles, and configurable icons and colors
- Math via MathJax — inline, block, and ` ```math ` fences — with a Copy SVG button on block equations
- Mermaid diagrams rendered live and matched to the active editor theme
- Code blocks syntax-highlighted with Shiki, following the active editor theme
- Commands to insert code blocks, callouts, and Mermaid diagrams
- An editable playground that tours every feature
